## 📚 EXAMENS DISPONIBLES

Tous les niveaux du CECRL (Cadre Européen):

• A1 - Débutant (80€)
• A2 - Élémentaire (90€)
• B1 - Intermédiaire (100€)
• B2 - Intermédiaire+ (110€)
• C1 - Avancé (120€)
• C2 - Maîtrise (130€)

Chaque examen évalue:
  1. Lecture (Lesen)
  2. Écoute (Hörverstehen)
  3. Écriture (Schreiben)
  4. Expression orale (Sprechen)

## 🎓 CAS D'USAGE COMPLETS

### Cas 1: Inscription d'un Étudiant
  1. Visiter la plateforme → Page d'accueil
  2. Cliquer "S'inscrire"
  3. Remplir le formulaire (prénom, nom, email, téléphone, pays, date naissance)
  4. Créer mot de passe
  5. Recevoir un email de vérification
  6. Cliquer sur le lien
  7. Email vérifié → Connexion possible
  8. Accès au tableau de bord personnel

### Cas 2: Inscription à un Examen
  1. Connecté en tant qu'étudiant
  2. Aller à "Examens"
  3. Sélectionner un examen
  4. Cliquer "S'inscrire"
  5. Confirmer l'inscription
  6. Effectuer le paiement
  7. Inscription confirmée
  8. Voir dans le tableau de bord

### Cas 3: Gestion Admin (Créer un Examen)
  1. Connecté en tant qu'admin
  2. Aller à Administration → Gestion des examens
  3. Cliquer "Nouvel examen"
  4. Remplir: Niveau, Date, Lieu, Capacité, Prix
  5. Publier l'examen
  6. Examen visible pour les étudiants
  7. Admin peut voir les inscriptions en temps réel

### Cas 4: Publication des Résultats
  1. Connecté en tant qu'admin/examinateur
  2. Aller à l'examen
  3. Cliquer "Saisir les résultats"
  4. Pour chaque étudiant:
     - Entrer scores (lecture, écoute, écriture, orale)
     - Définir niveau atteint (A1-C2)
     - Marquer comme Réussi/Échoué
  5. Publier tous les résultats
  6. Les étudiants voient leurs résultats
